# PDFCraft marketing kit

Ready-to-use assets for promoting PDFCraft on X, Instagram, and YouTube.

| File | What it is |
|---|---|
| `social-promo.html` | 4 social-sized promo graphics (brand gradient). Open in a browser, screenshot each frame. |
| `social-copy.md` | Positioning + paste-ready copy for X (thread + single), Instagram (carousel caption), YouTube (comment + video). |

## Turning the graphics into images

`social-promo.html` has 4 labelled frames at exact social sizes:

- **Frame 1** — 1080×1080 hero (Instagram feed / X)
- **Frame 2** — 1080×1080 feature grid (carousel slide 2)
- **Frame 3** — 1080×1080 privacy hook (carousel slide 3)
- **Frame 4** — 1600×900 (X card / YouTube thumbnail / banner)

To export them as PNGs:

1. Open `social-promo.html` in Chrome.
2. Open DevTools → right-click the `.frame` element in the Elements panel →
   **Capture node screenshot**. You get a pixel-perfect PNG at the frame's size.
   (Or just screenshot the frame on screen.)

Colors and wording match the live landing page (`apps/landing/`), so the
graphics stay on-brand.
